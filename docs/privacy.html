Overview

Self-Drive Trip Planner is an open-source local tool for generating road-trip data, HTML pages, route maps, and manifests from itinerary text.

Data You Provide

The tool processes itinerary text, route stop names, optional trip titles, optional start dates, and optional map API keys configured by you.

Local Storage

Generated outputs are written to local folders such as trip-output/ or docs/. API keys should be stored only in local environment variables or a local .env file, which is ignored by git.

External Services

When AMAP_KEY or GAODE_KEY is configured, the tool sends stop names and coordinates to Gaode/Amap Web Service to geocode stops and calculate driving routes. Without a key, the tool uses local estimated fallback data where possible.

What Is Not Collected

This project does not operate a backend service, account system, telemetry pipeline, or analytics database for your local runs.
